### 🤖 1. Inteligencia Artificial y Sistemas Agénticos (`axon-infer`, `yaai`, `yaai_ui`, `LocalAI`, `llamafile`, `odoo-openai`)

-   **Objetivo:** Consolidar motores de inferencia local, despliegues privados de LLMs y interfaces agénticas.

-   **Integración RIS:**

    -   Utilizar `axon-infer`, `LocalAI` y `llamafile` como la base tecnológica para los flujos de migración de sistemas heredados mediante IA de alta integridad.

    -   Conectar `yaai` y `yaai_ui` con las dinámicas de las *Code Parties* y hackathons para que los estudiantes construyan extensiones e interfaces conversacionales.

### 💻 2. Aplicaciones de Escritorio y Core (`desktop`, `server`, `hjCAD`, `2UML`, `Apollon`)

-   **Objetivo:** Potenciar las herramientas de diseño asistido, modelado de arquitectura y software de escritorio multiplataforma.

-   **Integración RIS:**

    -   Vincular `hjCAD`, `2UML` y `Apollon` al portafolio educativo STEM y de simuladores interactivos de código abierto.

    -   Usar los repositorios `server` y `desktop` para estructurar la arquitectura base de las soluciones SaaS y plataformas comerciales de la organización.

### 🌐 3. Ecosistema Empresarial y Gestión (`open-mercato`, `ever-gauzy`, `nextcloud-vm`, `bcrp-cli`)

-   **Objetivo:** Proveer soluciones robustas para gestión empresarial, ERP, código abierto y automatización de datos financieros/estatales.

-   **Integración RIS:**

    -   Alinear `ever-gauzy` y `open-mercato` con las vías de alianzas comerciales y representación SaaS para los miembros del equipo.

    -   Integrar `bcrp-cli` y `nextcloud-vm` dentro de las herramientas de infraestructura segura y automatización de procesos para la comunidad.

### 🔬 4. Ciencia Abierta e Innovación Avanzada (`open-science`, `iota-sdk`)

-   **Objetivo:** Impulsar la investigación científica abierta, tecnologías de libro mayor descentralizado y protocolos de comunicación.

-   **Integración RIS:**

    -   Conectar `open-science` con las iniciativas de certificación académica de posgrado de bajo costo y alto rendimiento.

    -   Explorar `iota-sdk` para proyectos experimentales de hardware libre, IoT y trazabilidad segura en los retos de la comunidad.
